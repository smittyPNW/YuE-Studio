# Campaign artwork

These images were created with the built-in imagegen tool using the actual app icon and captured app screens. They are promotional compositions, not pixel-exact screenshots. See `../screenshots/` for unmodified captures.

`hero.png`: public-source campaign banner. `mastering.png`: optional private-engine integration feature. The private ReSoul engine is supplied separately and is not included in this repository.

Do not imply that ReSoul is bundled with the public source build, that the model weights use Apache-2.0, that a notarized installer is available, or that this edition beats a named commercial service.
