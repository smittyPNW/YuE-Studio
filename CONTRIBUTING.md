# Contributing

Keep the song and the user's existing audio safe. Explain the behavior your change improves, preserve full-quality generation defaults, and include focused checks for affected workflows.

Run the public checks in `docs/SETUP.md`. For UI work, attach actual light/dark screenshots. Distinguish a build, a protocol test, a real model render, and listening evidence. Do not use generated marketing compositions as proof of the actual interface.

Do not commit secrets, model weights, audio libraries, personal paths, support logs, private ReSoul source/catalogs, or licensed engine binaries. The public tree guard is a baseline check, not a substitute for reviewing every staged file.

The public app and protocol can be improved without ReSoul source. Changes to engine behavior belong in the private engine project. Do not open issues requesting unpublished source or copy private presets into fixtures.

Preserve upstream licenses and attribution. Contributions to public code are supplied under the repository's Apache-2.0 license.
