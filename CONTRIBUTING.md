# Contributing

Keep the song and the user's existing audio safe. Explain the behavior your change improves, preserve full-quality generation defaults, and include focused checks for affected workflows.

Run the public checks in `docs/SETUP.md`. For UI work, attach actual light/dark screenshots. Distinguish a build, a protocol test, a real model render, and listening evidence. Do not use generated marketing compositions as proof of the actual interface.

Do not commit secrets, model weights, audio libraries, personal paths, support logs, commercial-app source outside the selected engine, or unreviewed binaries. The public tree guard is a baseline check, not a substitute for reviewing every staged file.

Studio Mastering contributions must preserve the engine license and notices. Test source preservation, non-overwrite delivery, cancellation, finite output, and generation/mastering exclusion. Do not change full-quality generation settings for speed without making it an explicit user choice.
